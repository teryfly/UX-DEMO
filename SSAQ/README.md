# 手术安全核查制度闭环管理系统 · 仿真演示前端

依据 `ux-desgin.docx`（用户故事 / 用户旅程 / 信息架构 / 低保真原型 / 交互规范）实现的**高仿真演示前端**。
全部数据通过 **FHIR R4 RESTful 风格**在浏览器缓存（内存 + localStorage）中进行 **CRUD 模拟**，
依赖的基础数据（患者、医务人员及资质、手术、核查表模板、违规与签名记录等）已按业务逻辑预置为初始种子数据。

支持 **6 种角色实时切换**，可完整走通「配置 → 三方核查 → 监督 → 分析」业务闭环。

---

## 一、运行方式

需通过 HTTP 提供页面（Babel 需以 XHR 加载 `src/*.jsx`，`file://` 直接打开会被浏览器拦截）。

```bash
./start.sh            # 默认 http://localhost:8099/
# 或自定义端口
./start.sh 8080
# 或手动
python3 -m http.server 8099
```

然后浏览器打开 `http://localhost:8099/`。所有依赖（React 18 / Ant Design 5 / dayjs / icons / Babel）
均已下载到 `vendor/`，**完全离线可用**。

> 顶部「**FHIR 控制台**」按钮可实时查看每一次操作对应的模拟 HTTP 请求（GET/POST/PUT/DELETE）与缓存资源量。
> 黄色条「**演示角色切换**」可一键切换 6 种角色；右上角「重置演示数据」恢复初始状态。

## 四、推荐演示流程（完整业务闭环）

1. **系统管理员**：「手术安全核查表配置」列表点[配置]进入编辑器 → 「从模板加载」/「+新增核查项」→ [确认生效]（自动校验三阶段必填项，缺失会列出）→ 查看**操作日志**；「核查表模板详情」看分阶段核查项（共X项必填Y项）与**版本更新记录**；「核查卡控规则配置」(6条+拦截条件)、「核查时间规范配置」(15/15/10+超时分类)、「手术风险评估标准配置」(ASA+NNIS、可启停)。
2. 切换 **麻醉医生** → 「麻醉前核查」（默认手术 OR-03 李国华·普外·阑尾切除术）：逐项勾选 → **逐项确认并签名**（CA 电子签名 + 资质校验）。
3. 切换 **主刀医生** → 同一手术签名；再切换 **洗手护士** 签名 → 三方齐全后**自动放行**，解锁麻醉记录流程，「开刀前核查」解除卡控。
4. 体验卡控：OR-03 未完成麻醉前时直接进「开刀前核查」→ 显示**强制卡控拦截**，点击「尝试强制启动」生成**违规日志**。
5. 体验资质校验：手术选择器切到 **OR-04（孙丽娟·神外）**，其麻醉医生「孙立」执业资质已过期 → 签名被拒绝并记录**资质异常**违规。
6. 体验超时：勾选「模拟核查超时」后完成三方签名 → 自动记录**超时违规**（按人员延迟/术中突发/系统异常归因）。
7. 切换 **手术室管理部门** →「核查执行看板」(6台手术并行状态、当前阶段、资质/超时预警、阶段完成率)；「违规记录」(3类统计卡 + 按类型/人员/手术间筛选，超时违规可编辑分类)。
8. 切换 **医疗质量管理部门** →「核查统计」(核心指标卡 + 近12周完成率趋势 + 问题分布 + ASA分布 + **手术部位二次核对**：OR-02/OR-05 申请与核查不一致标红)；「核查质量报告」**生成并自动归档**报告。

> 内置种子数据：12 个核查表模板（已生效/草稿/停用）、6 台手术（OR-01~06，覆盖进行中/卡控/资质异常/已完成/待核查）、16 名医务人员（含 2 名资质过期）、6 条卡控规则、ASA+NNIS 风险标准、6 条违规记录、2 份历史质量报告。

## 五、FHIR 资源映射

| 业务对象 | FHIR 资源 | 说明 |
|---|---|---|
| 患者基本信息 | `Patient` | EMR 自动带入 |
| 医务人员 | `Practitioner` | 含执业资质 |
| 角色与资质有效性 | `PractitionerRole` | 资质校验依据 |
| 手术（台次） | `Encounter` | 手术间/科室/三方参与者/阶段状态 |
| 拟行术式 / 手术部位 | `Procedure` | 含申请时部位（用于二次核对） |
| 核查表模板 | `Questionnaire` | 按阶段×角色分组的核查项 |
| 三方核查结果 | `QuestionnaireResponse` | 三方逐项确认与签名状态 |
| CA 电子签名 / 配置变更 | `Provenance` | 签名留痕、版本与配置可追溯 |
| 违规记录（卡控/资质/超时） | `AuditEvent` | 多维度追溯 |
| 手术风险评估 | `Observation` | ASA 分级 |
| 质量评价报告 | `DocumentReference` | 生成并归档 |
| 卡控规则/时间规范/评估标准 | `GateRule`/`TimeNorm`/`RiskStandard` | 配置项（FHIR Basic 封装） |
